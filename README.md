## Klasör Yapısı
- `src/model` ortak sınıflar
- `src/veriyapilari` her üyenin kendi veri yapısı
- `src/arayuz` arayüz kodları
- `docs` dökümanlar ve ortak sözleşme
- `uml` UML diyagramları
- `data` örnek veriler
